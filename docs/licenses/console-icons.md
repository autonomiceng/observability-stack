# Console icons

The Stack Console's marks under `docker/caddy/console/icons/` are the same local files as the
Platform Edge console's, so rendering never contacts third-party image services. Icons are
decorative; adjacent text names each link. Product names and marks belong to their owners
and imply no endorsement.

- Observability mark: an original SVG from platform-edge.
- Grafana: https://github.com/grafana/grafana/blob/main/public/img/grafana_icon.svg
- Alloy: https://github.com/grafana/alloy/blob/main/docs/sources/assets/alloy_icon_orange.svg
- Loki: https://grafana.com/static/img/logos/logo-loki.svg
- Mimir: https://grafana.com/static/img/logos/logo-mimir.svg
- Tempo and Caddy: https://github.com/homarr-labs/dashboard-icons/tree/main/svg (tempo.svg, caddy.svg)
- RustFS: https://github.com/rustfs/console/blob/main/app/icon.svg
- GitHub mark: https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg (MIT; see [octicons.txt](octicons.txt)), inlined in `index.html` so it takes the text colour.
